# Preacher Armor and Wasteland Gear Mod

## Overview
This mod for "7 Days to Die" enhances the early game experience by granting players a full set of Preacher Armor along with essential survival gear from "The Wasteland" mod upon reaching level 2.

## Features
- **Preacher Armor Set**: Includes Preacher Hat, Outfit, Gloves, and Boots at quality 6.
- **Wasteland Essentials**: 
  - 10 Hobo Stew
  - 100 rounds of 10mm ammunition
  - 1 10mm Pistol (quality 6)
  - 1 Hunting Knife (quality 6)

## Installation
1. **Download**: Download the mod files from [insert download link here if applicable].
2. **Directory Setup**:
   - Place the `PreacherArmorAndWastelandGear` folder into your `7 Days To Die\Mods` directory.
3. **Enable Mod**:
   - Launch the game and enable the mod through the Mods menu in the game's settings, or manually add the mod to `config.xml` in `7 Days To Die\Data\Config` under the `<active_mods>` section like this:
     ```xml
     <active_mods>
         <mod>PreacherArmorAndWastelandGear</mod>
     </active_mods>
     ```
